# نظام إدارة الطلبة والرسائل | School Messaging System

نظام ويب بلغة عربية لإدارة فصول وطلبة المدرسة، وإرسال رسائل وإشعارات رسمية إلى أولياء الأمور
عبر البريد الإلكتروني، مع **٣٦ قالب رسالة احترافي جاهز** وتحكّم كامل في كل عنصر داخل الرسالة.

> A Flask web app (Arabic/RTL) for managing school classes and students, and sending
> professionally formatted email notifications to parents — with 36 ready-made templates
> and full control over every element of the message.

---

## المزايا

**إدارة الطلبة**
- فصول وطلبة مع بحث فوري بالاسم أو الهاتف أو البريد أو الفصل
- فلترة حسب الفصل، وإضافة وتعديل وحذف الطلبة
- لوحة إحصائيات (عدد الطلبة، الفصول، متوسط الفصل، الرسائل المُرسلة)

**الرسائل**
- ٣٦ قالباً جاهزاً بنص عربي رسمي كامل موزّعة على ٧ تصنيفات:
  سلوكية · أكاديمية · استدعاء · إيجابية · صحية · إدارية · أخرى
- كل قالب يحتوي على: فقرة افتتاحية، نص الرسالة، نقاط، الإجراء المطلوب، خاتمة، وصفوف جدول بيانات
- **تحكّم كامل**: كل جزء في الرسالة له مفتاح إظهار/إخفاء ونصّه قابل للتعديل —
  الترويسة والشعار، الشارة، بطاقة الطالب، التحية، جدول البيانات، النص، النقاط،
  الإجراء المطلوب، زر، الخاتمة، التوقيع، صندوق التواصل، والتذييل
- تحكّم في اللون الأساسي ولون الخلفية وحجم الخط
- **معاينة حيّة** للإيميل أثناء الكتابة
- حفظ أي رسالة **كقالب خاص** لإعادة استخدامها
- إعدادات افتراضية تُطبَّق على كل رسالة جديدة (اسم المدرسة، الشعار، التوقيع، بيانات التواصل)

**المتغيّرات** — تُكتب في أي حقل وتُستبدل تلقائياً:

| المتغيّر | القيمة |
|---|---|
| `{student}` | اسم الطالب |
| `{class}` | الفصل |
| `{school}` | اسم المدرسة |
| `{date}` | تاريخ اليوم بالعربية |
| `{phone}` | هاتف الطالب |
| `{email}` | بريد ولي الأمر |

## التشغيل

```bash
git clone https://github.com/3mrlogic/MohamedAli.git
cd MohamedAli
pip install -r requirements.txt
python app.py
```

ثم افتح المتصفح على <http://localhost:5000>

عند أول تشغيل يُنشئ النظام ملف `data.json` فارغاً تلقائياً، وتظهر لك **شاشة الإعداد الأول**:

| الحقل | الشرح |
|---|---|
| البريد الإلكتروني | حساب Gmail الذي تُرسَل منه الرسائل |
| كلمة مرور تطبيقات Gmail | App Password المكوّنة من ١٦ خانة — **وليست** كلمة مرور حسابك |
| كود الدخول | كود تختاره أنت للدخول إلى النظام لاحقاً |

> **كلمة مرور التطبيقات:** فعّل التحقق بخطوتين في حساب Google ثم أنشئها من
> Google Account → Security → App passwords.

تسجيل الدخول يتم **مرة واحدة فقط** ويبقى محفوظاً حتى بعد إعادة تشغيل السيرفر،
ولا يُطلب مجدداً إلا بعد تسجيل الخروج.

### متغيّرات البيئة (اختيارية)

| المتغيّر | الافتراضي |
|---|---|
| `SECRET_KEY` | يُولَّد ويُحفظ في `.secret_key` |
| `SMTP_SERVER` | `smtp.gmail.com` |
| `SMTP_PORT` | `587` |

## النشر على الإنترنت (Vercel + Neon)

نظام ملفات Vercel **للقراءة فقط ويُمسح مع كل طلب**، لذلك لا يصلح ملف `data.json` للتخزين هناك.
يستخدم المشروع طبقة تخزين تختار تلقائياً:

| البيئة | التخزين |
|---|---|
| محلياً (بدون `DATABASE_URL`) | ملف `data.json` — لا يحتاج أي إعداد |
| على Vercel (مع `DATABASE_URL`) | قاعدة Postgres على Neon |

### ١. أنشئ قاعدة بيانات على Neon

1. ادخل <https://neon.tech> وسجّل بحساب GitHub (الخطة المجانية كافية).
2. **Create project** واختر أقرب منطقة (مثلاً Frankfurt).
3. من **Connection string** انسخ الرابط، واختر نسخة **Pooled connection** —
   مهمّة لأن Vercel تفتح اتصالات كثيرة قصيرة العمر. يكون شكله:

   ```
   postgresql://user:pass@ep-xxx-pooler.eu-central-1.aws.neon.tech/neondb?sslmode=require
   ```

### ٢. ارفع بياناتك إلى القاعدة

من مجلد المشروع على جهازك:

```powershell
pip install psycopg2-binary
$env:DATABASE_URL="<الرابط الذي نسخته>"
python migrate_to_neon.py
```

يطبع السكربت عدد الفصول والطلبة قبل الرفع ويتحقق بعده.
أضف `--no-auth` إذا لم ترغب بنقل كلمة مرور البريد، و`--force` للكتابة فوق بيانات موجودة.

### ٣. اربط Vercel بالمستودع

1. <https://vercel.com> → **Add New → Project** → استورد هذا المستودع.
2. Framework Preset: **Other** (الإعدادات في `vercel.json`).
3. قبل الضغط على Deploy افتح **Environment Variables** وأضف:

   | الاسم | القيمة |
   |---|---|
   | `DATABASE_URL` | رابط Neon المجمَّع (Pooled) |
   | `SECRET_KEY` | أي نص عشوائي طويل — `python -c "import secrets;print(secrets.token_hex(32))"` |

4. **Deploy**.

### ٤. تأكّد أن كل شيء سليم

افتح `https://<مشروعك>.vercel.app/api/health` — المتوقع:

```json
{"ok": true, "storage": "Postgres (Neon)", "students": 351, "classes": 16, "has_setup": true}
```

لو ظهر `"storage": "ملف محلي data.json"` فمعناه أن `DATABASE_URL` لم تصل للتطبيق —
راجع متغيّرات البيئة ثم أعد النشر (Redeploy).

### ملاحظات مهمة

- **إرسال البريد:** الاتصال بـ Gmail عبر SMTP من دالة serverless قد يكون بطيئاً؛
  لذلك رُفع حد التنفيذ إلى 60 ثانية في `vercel.json`. إن فشل الإرسال باستمرار
  فالبديل هو استخدام واجهة HTTP لخدمة بريد (مثل Resend أو SendGrid) بدل SMTP.
- **الكتابة المتزامنة:** تُحفظ البيانات كمستند JSONB واحد، والكتابة الأخيرة تغلب.
  هذا مناسب لمستخدم إداري واحد؛ ومع عدة مستخدمين في نفس اللحظة يلزم تقسيم الجداول.
- **الخصوصية:** بيانات الطلبة تعيش في قاعدة Neon الخاصة بك ولا تُرفع إلى المستودع أبداً
  (`data.json` مستبعد في `.gitignore`). الموقع محميّ بكود الدخول فقط، فاختر كوداً قوياً.

## بنية المشروع

```
app.py                  السيرفر، الجلسات، واجهات API، وبناء رسالة HTML
db.py                   طبقة التخزين (Postgres على الإنترنت / ملف محلياً)
message_templates.py    مكتبة القوالب الـ٣٦ الجاهزة
templates/index.html    الواجهة كاملة (HTML + CSS + JS)
migrate_to_neon.py      رفع البيانات المحلية إلى Neon
api/index.py            نقطة الدخول على Vercel
vercel.json             إعدادات النشر
data.json               قاعدة البيانات المحلية — لا تُرفع إلى Git
```

محلياً: ملف JSON واحد بلا أي إعداد. على الإنترنت: نفس المستند داخل Postgres.

## ملاحظات أمنية مهمة

- **`data.json` و `.secret_key` مستبعدان في `.gitignore` ولا يجب رفعهما.**
  الأول يحتوي على أسماء الطلبة وأرقام هواتف أولياء الأمور وبريدهم، بالإضافة إلى
  كلمة مرور تطبيقات Gmail؛ والثاني هو مفتاح توقيع الجلسات.
- عند النشر على Vercel يعمل التطبيق في الوضع الإنتاجي تلقائياً (`debug` لا يُفعَّل)،
  وتُوفَّر HTTPS من المنصة. يبقى مطلوباً: اختيار **كود دخول قوي**،
  وتقييد مصادر `CORS` إن لم تكن هناك واجهة خارجية، وإضافة حدّ لمحاولات تسجيل الدخول.
- عند تسجيل الخروج يتغيّر رمز الجلسة في قاعدة البيانات، فتبطل كل الجلسات القديمة فوراً.
- كل نص يكتبه المستخدم يُهرَّب قبل إدراجه في الـ HTML لمنع حقن الوسوم.
